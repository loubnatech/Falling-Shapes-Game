Contribution Guidelines
Coding Standards:
Follow existing code style and patterns

Use clear and descriptive variable/function names

Add comments for complex logic

Ensure compatibility with Python 3.6+

Design Guidelines:
Maintain consistent user experience

Use existing color schemes and design patterns

Ensure new additions don't break existing functionality

Documentation Guidelines:
Document new features in English

Add usage examples where appropriate

Update README.md when adding significant features

Review Process
Maintainers will review pull requests

We may request changes before merging

Once approved, your PR will be merged into main

You'll be notified when your contribution is merged

Reporting Bugs
When reporting bugs, please include:

Clear description of the issue

Steps to reproduce the problem

Screenshots if applicable

System information (OS, Python version)

Suggesting New Features
To suggest new features:

Clearly explain your idea

Provide examples of how it would work

Explain the benefit to the game

Consider implementation complexity

Thank you for helping make this game better! ❤️
